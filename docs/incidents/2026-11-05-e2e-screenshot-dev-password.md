# 事故：E2E 失敗截圖拍到開發環境 WP 編輯者密碼（2026-11-05）

- **等級**：SEV4（只涉及 Claude 雲端 VM 內隨機產生的開發用合成密碼；正式環境不存在此帳號；未提交 Git、未上傳 CI artifact）
- **經過**：預覽 E2E 第一次執行時，`wp-login.php` 載入後約 200ms 以腳本把焦點移回帳號欄，密碼被輸入帳號欄；登入失敗截圖（Git 忽略的 `tests/e2e/test-results/`）以明文顯示該密碼，且截圖內容曾被 E2E 子代理讀入對話。
- **處置**：
  1. 截圖於下一次執行時由 Playwright 清空輸出目錄移除；CI 不上傳 `test-results/`。
  2. 已輪替開發環境 `wp_editor_password`（新密碼經 stdin 更新，不出現在命令列或輸出），以新密碼登入驗證成功。
  3. E2E 登入 helper 改為等待焦點腳本完成後再填寫、填完驗證欄位；不符時先清空兩欄再拋錯，失敗截圖不會含密碼。
- **防再發**：Playwright trace／video 維持關閉；2FA 秘鑰與復原碼頁面整檔不截圖。
