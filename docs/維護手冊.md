# 維護手冊（總覽與入口）

這份手冊給接手維護 mysite 的人：先看這裡掌握全貌與日常命令，細節再進各專題手冊。內容編輯操作請看 `docs/內容編輯手冊.md`。

## 1. 系統全貌

| 元件 | 角色 | 位置 |
|---|---|---|
| gateway（Nginx） | 唯一對外入口；依網域分流到主站與 CMS；登入頁 POST 限流 | `infra/nginx/gateway/` |
| app-web／app-php（Laravel 13） | 公開前臺、內容整合、模擬商店、管理後臺 | `app/` |
| app-worker／app-scheduler | 佇列與排程（內容快取清理每小時、保存期限每日 03:17、排程心跳每分鐘） | `app/routes/console*.php` |
| wp-web／wp-php（WordPress 7.1） | 內容編輯（文章、頁面、影片、Podcast、選單、品牌） | `wp/` |
| wp-jobs | WP 排程、事件 outbox 投遞、對帳（含心跳） | `infra/images/wordpress/jobs.sh` |
| mysql（MySQL 8.4） | 兩個資料庫、兩組帳號，互相不可存取 | `infra/mysql/init/` |

兩個系統只以 REST 與簽章事件整合，契約在 `docs/API契約.md`；設定鍵與秘密檔清單在 `docs/設定目錄.md`；設計決定與理由在 `docs/架構決策.md`。

## 2. 版本與相依

- 所有版本、映像 digest、檔案 hash 只寫在 `infra/versions.env`，查核來源記在 `docs/版本查核.md`，機器可讀版本在 `docs/versions.lock.json`。
- 升級流程：先查官方來源 → 改 `infra/versions.env` 與 `docs/版本查核.md` → 重建映像（`scripts/lib/build.sh` 為唯一建置入口）→ 跑完整驗證（第 4 節）→ 才能進 release。
- 每週弱點稽核：`.github/workflows/dependency-audit.yml`（合併到預設分支後才會依排程執行）；每次驗證也會跑 `tests/governance/scan.sh`（映像、Composer、npm、WordPress 核心與外掛）。

## 3. 日常命令（雲端 Linux 開發環境）

```bash
bash scripts/cloud/session-start.sh          # 讀狀態、恢復開發服務（不重設資料）
bash scripts/cloud/up.sh --env=development    # 啟動並等待全部服務就緒
bash scripts/cloud/doctor.sh --env=development # HTTP／DB／排程／安全設定實測
bash scripts/cloud/checkpoint.sh --reason=<原因> # 中斷前保存狀態
```

所有腳本都有 `--help`，exit code 統一：0 成功、10 參數錯、20 缺外部前置、21 建議改用 GitHub Actions、30 測試失敗、40 禁止的操作、50 部署或還原未完成。

## 4. 驗證

```bash
bash scripts/ci/verify.sh --scope=content      # 內容站（商店關閉）
bash scripts/ci/verify.sh --scope=simulation   # 內容＋模擬商店
```

- 步驟：靜態檢查 → 乾淨 testing 環境 → 冪等 → doctor → PHPUnit（MySQL 測試庫，覆蓋率門檻 70%）→ WP 契約 → E2E（三種寬度）→ 部署工具 → 治理檢查與弱點掃描 → 彙整證據。
- 證據產生在 `docs/evidence/<run-id>/`；GitHub Actions 的證據以 `scripts/ci/import_evidence.py` 匯入（會核對 run ID 與受測 commit）。
- 驗收登錄表 `tests/acceptance/registry.json` 只記實際執行過的結果；未跑寫 `NOT_RUN`，缺外部資源寫 `BLOCKED_EXTERNAL`。

## 6. 不可做的事

- 不在正式環境執行 `down -v`、`migrate:fresh`、全域 prune；`up` 與 `session-start` 不含任何重設。
- 秘密只放 `.runtime/secrets/<env>/`（Git 忽略）並以 `*_FILE` 讀取；不得寫進 log、證據、截圖或對話。
- 富文字只經 `SafeContent` 與 `<x-rich-content>` 輸出；其他 `{!! !!}` 會被 CI 擋下。
- `COMMERCE_MODE=real` 一律拒絕；不收卡號、真實地址、電話。
- 上傳發布清單不等於部署成功；未在真實主機驗證前，不宣稱已上線。
