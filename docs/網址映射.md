# 網址映射（CMS → 主站）

主站（Laravel，`MYSITE_APP_URL`）是所有公開內容的 canonical。WordPress（CMS）只負責編輯；`site-content` 外掛把 WordPress 產生的內容連結改寫到主站，mu-plugin `mysite-cms-frontend.php` 把 CMS 前臺請求 301 轉到主站對應網址。

## 1. 內容連結（`site-content` 外掛，`includes/url-mapping.php`）

| WordPress 物件 | 主站網址 | 使用的 WordPress 篩選器 |
|---|---|---|
| 文章 `post` | `/articles/{slug}` | `post_link` |
| 頁面 `page` | `/pages/{slug}` | `page_link` |
| 影片 `sc_video` | `/videos/{slug}` | `post_type_link` |
| Podcast `sc_podcast` | `/podcasts/{slug}` | `post_type_link` |
| 分類 `category` | `/categories/{slug}` | `term_link` |
| 標籤 `post_tag` | `/tags/{slug}` | `term_link` |
| 文章列表 | `/articles` | `post_type_archive_link`（`post`） |
| 影片列表 | `/videos` | `post_type_archive_link`（`sc_video`） |
| Podcast 列表 | `/podcasts` | `post_type_archive_link`（`sc_podcast`） |

規則：

- 只有「已發布」或「私人」內容改寫成主站網址；草稿、待審、排程保留 WordPress 原生連結（`?p=ID`），讓區塊編輯器的「預覽」經由 CMS 前臺轉入本外掛的預覽流程（見第 3 節）。
- 區塊編輯器的「網址／slug」欄位顯示主站網址範本（`get_sample_permalink()` 的 `%postname%`／`%pagename%` 佔位字保留），修改 slug 後主站網址同步改變。
- slug 為 WordPress 的 `post_name`；中文 slug 以 URL 編碼形式（例如 `%e7%a4%ba%e4%be%8b`）原樣放入路徑。
- 頁面只取自身 slug，不含父頁面路徑（主站路由為 `/pages/{slug}`）；不同父頁面下的同名 slug 會在主站碰撞，請避免。
- 已改名的 slug 目前不自動產生舊網址轉址（v5 §9.1：首次上線前沒有舊站網址需要承接）；需要時另行記錄 301 對照。
- `home_url()`、`site_url()`、`wp-admin`、REST 與媒體網址都不改寫。媒體（`/wp-content/uploads/...`）仍由 CMS 主機提供。

## 2. CMS 前臺轉址（mu-plugin `mysite-cms-frontend.php`）

在 `template_redirect`（優先順序 0）處理，所有轉址皆送 `X-Robots-Tag: noindex, nofollow`。

| CMS 請求 | 轉到主站 | HTTP |
|---|---|---|
| 首頁 `/` | `/` | 301 |
| 公開的文章、頁面、影片、Podcast（任何 WordPress 網址形式，含 `?p=ID`） | 第 1 節的對應網址 | 301 |
| 非公開內容（草稿、私人、密碼保護、排程、垃圾桶）或不存在的網址 | `/`（不洩露 slug 或狀態） | 301 |
| 分類、標籤彙整 | `/categories/{slug}`、`/tags/{slug}` | 301 |
| 影片、Podcast 彙整 | `/videos`、`/podcasts` | 301 |
| 搜尋 `?s=…` | `/search?q=…`（最多 100 字） | 301 |
| Feed `/feed/` 等 | `/feed.xml` | 301 |
| 已登入且可編輯者的原生預覽（`?preview=true`） | `admin-post.php?action=site_content_preview…`（本外掛預覽流程） | 302 |

不受影響（交給 WordPress 或 Nginx 原生處理）：`/wp-admin/`、`/wp-login.php`、`/login`、`/admin`、`/dashboard`、`/wp-json/`（含 `?rest_route=`）、`/wp-content/uploads/`、`/wp-cron.php`、`/wp-admin/admin-ajax.php`、`/wp-admin/admin-post.php`、`robots.txt`。

WordPress 核心 sitemap（`/wp-sitemap.xml`）由 `mysite-security.php` 關閉；sitemap 與 RSS 只由主站產生（`/sitemap.xml`、`/feed.xml`）。

## 3. 草稿預覽

| 步驟 | 網址 |
|---|---|
| 編輯器「預覽」 | `{WP_PUBLIC_URL}/wp-admin/admin-post.php?action=site_content_preview&post={id}&_wpnonce=…` |
| 驗證後導向 | `{MYSITE_APP_URL}/preview/exchange?ticket=…`（302） |
| 主站讀取快照 | `GET https://wp-web:8443/wp-json/site-content/v1/preview/{type}/{id}?snapshot={sid}`（服務帳號＋`X-Mysite-Preview-Ticket`） |

## 4. 選單（`GET /wp-json/site-content/v1/menus/{primary|footer}`）

| 選單項目 | 輸出 |
|---|---|
| 內容（文章、頁面、影片、Podcast） | 主站相對路徑；目標非公開時整項（含子項）略過 |
| 分類、標籤 | `/categories/{slug}`、`/tags/{slug}` |
| 影片、Podcast 彙整 | `/videos`、`/podcasts` |
| 自訂連結：`/` 開頭 | 原樣（主站相對路徑） |
| 自訂連結：主站網址 | 轉為相對路徑 |
| 自訂連結：CMS 網址 | 能對應到公開內容才轉主站路徑，否則略過 |
| 自訂連結：其他 `https:` 網址 | 原樣，`external: true` |
| 自訂連結：`http:`、`mailto:`、`javascript:`、`//host` 等 | 略過 |

## 5. 驗證

`tests/contracts/wp/run.sh` 的 `cms_frontend_redirects_to_app`、`wp01_editor_creates_and_edits_via_gateway`（`link` 欄位指向主站）與 `api01_structure_and_full_paths`（選單網址）實際檢查上述規則。
