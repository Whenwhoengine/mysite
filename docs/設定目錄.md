# 設定目錄（GOV-01）

分層：版控設定（本檔、`infra/versions.env`、`app/config/*.php`）→ 環境設定（`.runtime/env/<env>.env` 或主機 `environments/<env>/config/compose.env`）→ 秘密（`*_FILE`）→ 執行狀態（DB、volume、發布序號）。

`app/config/mysite.php` 是 Laravel 讀取本案自訂鍵的唯一位置；`App\Support\Config\MysiteConfig::validate()` 在啟動時驗證（測試：`tests/Unit/Config/MysiteConfigTest.php`）。WordPress 端由 `wp/config/wp-config.template.php` 讀取。

## 非秘密設定

| 鍵 | 預設／來源 | 讀取位置 | 檢查 |
|---|---|---|---|
| `MYSITE_ENVIRONMENT`／`APP_ENV` | development／testing／staging／production | Compose → Laravel `app.env` | 其他值啟動失敗（entrypoint 與 MysiteConfig） |
| `WP_ENVIRONMENT_TYPE` | development／staging／production | wp-config | 其他值啟動失敗 |
| `APP_DEBUG` | production=false | `app.debug` | staging／production 為 true 時啟動失敗 |
| `APP_URL` | 開發 `http://127.0.0.1:8080`；正式為核准 HTTPS 網址 | `app.url` | staging／production 必須 https |
| `WP_PUBLIC_URL` | 開發 `http://127.0.0.1:8081` | wp-config `WP_HOME`、Laravel `mysite.wp_public_url` | 不得與 APP_URL 同 host；正式必須 https |
| `APP_LOCALE` | `zh_TW` | `app.locale` | 必須有 `lang/zh_TW` 資源 |
| `APP_TIMEZONE` | `Asia/Taipei` | `mysite.display_timezone`（框架儲存時區固定 UTC，見 ADR-012） | 必須是有效 IANA 時區 |
| `CONTENT_API_BASE_URL` | `http://wp-web:8080/wp-json/site-content/v1` | `mysite.content.api_base_url` | scheme http/https、host 在 `content.allowed_hosts`、路徑以 `/wp-json/site-content/v1` 結尾 |
| `CONTENT_PRIVATE_API_BASE_URL` | `https://wp-web:8443/wp-json/site-content/v1` | `mysite.content.private_api_base_url` | 必須 https；CA 檔存在 |
| `CONTENT_PRIVATE_API_CA_FILE` | `/run/secrets/internal_ca_cert` | `mysite.content.private_api_ca_file` | 檔案可讀 |
| `CONTENT_SERVICE_USERNAME` | `mysite-service` | `mysite.content.service_username` | 非空 |
| `CONTENT_EVENT_URL` | `http://app-web:8080/internal/content-events/v1` | WP 外掛（發送端） | 路徑固定 `/internal/content-events/v1` |
| `CONTENT_EVENT_KEY_ID` | `k1` | 兩端 | `[a-z0-9]{1,16}` |
| `CONTENT_CONNECT_TIMEOUT_SECONDS` | 2 | `mysite.content.connect_timeout` | 1–10 |
| `CONTENT_HTTP_TIMEOUT_SECONDS` | 5 | `mysite.content.timeout` | 1–30；冪等讀取最多 2 次嘗試 |
| `CONTENT_VISIBILITY_TTL_SECONDS` | 30 | `mysite.content.visibility_ttl` | 1–60（硬上限 60） |
| `CONTENT_BODY_CACHE_TTL_SECONDS` | 300 | `mysite.content.body_ttl` | 1–3600；供應仍受可見性期限約束 |
| `PREVIEW_TTL_SECONDS` | 600 | 兩端 | 60–900 |
| `PODCAST_AUDIO_ALLOWED_HOSTS` | 空＝只允許 `WP_PUBLIC_URL` 的 host | 兩端 | 逗號分隔 host，僅 https（開發允許 WP_PUBLIC_URL 原 scheme） |
| `COMMERCE_MODE` | `disabled` | `mysite.commerce.mode` | 只允許 disabled／simulation；`real` 啟動商務即拒絕 |
| `DB_CONNECTION` | `mysql` | `database.default` | 非 mysql 於非 testing 單元情境拒絕 |
| `DB_HOST`／`DB_PORT`／`DB_DATABASE`／`DB_USERNAME` | mysql／3306／mysite_app／mysite_app | `database.connections.mysql` | 帳號不得為 root |
| `CACHE_STORE`／`SESSION_DRIVER`／`QUEUE_CONNECTION` | database | 框架 | 資料表由 migrations 建立 |
| `SESSION_SECURE_COOKIE` | 正式 true | `session.secure` | staging／production 必須 true |
| `SIMULATION_DATA_RETENTION_DAYS` | 30 | `mysite.retention.simulation_days` | 1–365；專案預設，非法定期限 |
| `CART_RETENTION_DAYS` | 7 | `mysite.retention.cart_days` | 1–90 |
| `AUDIT_RETENTION_DAYS` | 90 | `mysite.retention.audit_days` | 7–730 |
| `TRUSTED_PROXIES` | edge 子網 | `bootstrap/app.php` trustProxies | 只信任 gateway 子網 |
| `DEPLOY_ENVIRONMENT`／`DEPLOY_CHANNEL`／`RELEASE_ID` | 部署清單提供 | `mysite.deploy.*` | staging／production 必須與簽章清單一致 |
| `MAIL_MAILER` | `log`（測試捕捉器） | `mail.default` | 正式郵件服務未核准前不得改為外寄 |

## 秘密（`*_FILE`）

| 秘密 | 檔名（`.runtime/secrets/<env>/`） | 供應對象 | 產生／輪替 |
|---|---|---|---|
| MySQL root | `mysql_root_password` | 僅 mysql 初始化 | bootstrap 首次產生；不給應用 |
| WP DB 密碼 | `wp_db_password` | mysql、wp-php、wp-jobs | `scripts/ops/rotate-secrets.sh --kind=wp-db` |
| Laravel DB 密碼 | `app_db_password` | mysql、app-* | `--kind=app-db` |
| Laravel APP_KEY | `app_key`（`base64:` 格式） | app-* | 不在重啟時生成；輪替影響加密資料與 Session |
| WP salts | `wp_salts`（8 行 `NAME=value`） | wp-php、wp-jobs | `--kind=wp-salts`（使所有登入失效） |
| 事件 HMAC | `content_event_hmac_key` | wp-*、app-* | `--kind=event-hmac`（新舊 key ID 過渡） |
| 預覽簽章 | `preview_signing_key` | wp-*、app-* | `--kind=preview`；與事件金鑰分開 |
| WP 服務帳號 Application Password | `wp_service_app_password` | app-* | bootstrap 以 WP-CLI 建立；`--kind=wp-service` |
| 內部 CA 憑證 | `internal_ca_cert` | app-*（只信任此 CA） | bootstrap 產生；CA 私鑰只留在 `.runtime/secrets/<env>/ca/` |
| wp-web 內部 TLS | `wp_internal_tls_cert`／`wp_internal_tls_key` | wp-web | 由內部 CA 簽發，SAN=`wp-web` |

規則（`App\Support\Secrets\SecretFiles` 與 wp-config 一致）：檔案必須存在、非空、其他使用者不可讀寫（0640 root:33 或更嚴）；去除結尾換行；單行秘密不得含換行；staging／production 缺任何必要秘密即拒絕啟動。

## PHP 啟動設定

`infra/php/security.ini`：`session.upload_progress.enabled=0`、`expose_php=Off`、`display_errors=Off`、`log_errors=On`。不是 Laravel `.env` 設定；`scripts/cloud/doctor.sh` 經 HTTP→Nginx→FPM 讀回兩個 Web SAPI 的實際值（內部診斷端點，需內部診斷權杖，不公開 phpinfo）。
