## 3. 實測紀錄

- **API 測試**（第一輪查錯修正後）：`PublicApiTest` 26 項、`PublicApiVisibilityTest` 8 項、`PublicApiHardeningTest` 6 項、`PublicApiSamplesTest` 72 項（有效 54＋無效 16＋完整性 1＋契約檔驗證 1）、`ApiMockExportTest` 9 項（6 個測試方法，其中一個以資料提供器跑 4 組）、`MediaPolicyTest` 29 項，全過。
- **全套 PHPUnit（development 容器）**：第一輪查錯修正後共 504 項，500 過；失敗 4 項全是 `BladeRawCheckTest`，原因是 development 的 app-php 容器沒有掛載 repo 的 `scripts/`（測試自己的訊息：「找不到 scripts/ci/check-blade-raw.sh：請在執行測試的容器掛載儲存庫的 scripts/」）。CI 的工具容器有掛載，這 4 項在 CI 執行；不是本次改動造成。
- **Blade 重構**：`PublicRoutesTest`、`FeedSitemapTest`、`VisibilityLeaseTest`（共 25 項）連同 `MediaPolicyTest`（29 項）一起跑，共 54 項，重構後全過。
- **gateway**：development 環境重建 gateway 映像後，`/api/v1/site`、`/api/`、`/api` 經 gateway 皆 404；`/`、`/articles` 照常 200；`nginx -t` 通過。
- **語意金絲雀**（定案 §6 F2）：每次只改一處、跑 `PublicApiTest`、再逐位元組復原（`cmp` 確認）。

| 改壞的地方 | 變紅的測試 |
|---|---|
| 影片 `video_unavailable` 寫死 false | 1 項（影片 ID 不合法） |
| API 的路由層 404 錯誤碼改回 `HTTP_404` | 2 項（slug 201 字、未知路徑） |
| `Cache-Control` 改成 `public, max-age=60` | 23 項（全部經 `api()` 檢查的請求） |
| 摘要多送內部 `id` | 8 項（契約 `additionalProperties: false` 擋下，另有 PAPI-05 字串檢查） |

復原後 26 項全綠。

- **Composer 安裝**：本 VM 對 GitHub 的壓縮檔下載（`api.github.com/.../zipball`、`codeload.github.com`）一律回 403，所以 `composer require` 解析鎖定檔成功、下載失敗；改以 `composer install --prefer-source`（經 git 取得）安裝。鎖定檔內容不受影響，CI 照常以壓縮檔安裝。新增的開發用相依（皆 MIT，`marc-mabe/php-enum` 為 BSD-3-Clause）：`osteel/openapi-httpfoundation-testing`、`league/openapi-psr7-validator`、`devizzent/cebe-php-openapi`、`nyholm/psr7`、`symfony/psr-http-message-bridge`、`symfony/cache`、`respect/validation`、`respect/stringifier`、`riverline/multipart-parser`、`justinrainbow/json-schema`、`marc-mabe/php-enum` 等，見 `app/composer.lock` 的 `packages-dev`。

## 5. 第一輪查錯（2026-11-06，委託人「使持節決行」：完成後驗錯兩次、每次思考兩遍）

| 發現 | 嚴重度 | 處置 |
|---|---|---|
| 經「`/index.php/api/v1/…`」可繞過 gateway 的 `/api/` 404（實測 200），連帶登入限流與 `/internal/` 前綴規則也能被繞 | 高 | gateway 兩份範本與 app-web 都加 `location ^~ /index.php/ { return 404; }`；Laravel 全域中介層 `PublicApiHeaders` 遇到非空 base URL 一律 404；doctor 新增 `GW-API` 探測；`PublicApiHardeningTest` 一項（金絲雀：拿掉檢查就變紅） |
| 修訂註記標記可藏字（例如註記內放 `<!--`）、可引用不存在的 ADR；執行契約的原件雜湊沒有程式比對 | 中 | 標記格式收窄（日期必填、不得含控制字元與 Markdown／HTML 符號）；check-state 檢查引用的 ADR 存在、執行契約比對 `prompt_sha256`；治理 EXEC-01 加「引用不存在的 ADR」「註記藏 `<!--`」兩個必須失敗的案例 |
| 框架預設 CORS 對 `api/*` 開放所有來源 | 中 | 新增 `app/config/cors.php`（paths 為空）；測試確認沒有 `Access-Control-Allow-Origin` |
