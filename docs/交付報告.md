## 5. 未驗證或有限制的部分

- 沒有任何真實主機上的驗證：HTTPS 憑證、主機重啟、告警送達、異地備份、正式秘密隔離、30 天可用性觀察。
- YouTube 與音訊的外部實際播放：雲端 VM 連不到外部影音服務，只驗了嵌入契約（iframe 網址、Range／206、MIME），實際播放要在 staging 以瀏覽器確認。
- `sandbox.yml`（無 Docker 時的備援入口）沒有實際觸發過：workflow_dispatch 需要該檔已在預設分支。CLD-08 驗的是「Docker 不可用時 verify 回 exit 21 並指向 sandbox.yml」以及 ci.yml 結果的讀回核對。
- WordPress 外掛弱點資料來自 WPVulnerability 公開 API。該服務沒有明確的服務條款或保證，結果僅供參考；Wordfence 的資料需要免費 API 金鑰（需委託人申請）。
- 已知功能缺口（`docs/state/blockers.md`）：
  - 事件 HMAC 與預覽簽章不支援多金鑰並存的平順輪替（目前輪替腳本會拒絕自動輪替）。
  - CMS 沒有單獨的維護模式。
  - WordPress Two Factor 外掛 0.17.0 以明文存放 TOTP 秘鑰（外掛本身的行為）。
  - uploads 內的檔案知道網址就能讀，包含草稿使用的媒體（WordPress 固有行為）。
  - wp-web 未設定 real_ip，WordPress 記錄到的登入 IP 是 gateway 位址。
- 合併後 release.yml 的自動發布預設關閉（推送 GHCR 可能佔用付費額度），要由委託人設定 `MYSITE_AUTO_RELEASE=true` 才會啟動。
