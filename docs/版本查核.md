## 映像 registry 備援（ADR-004）

Docker Hub 匿名拉取在本 VM 出現 `429 Too Many Requests`。同一批 Docker Official Images 也由 Docker 發布於 Amazon ECR Public（`public.ecr.aws/docker/library/*`）。本次以**相同 digest**從 ECR Public 實際拉取成功（php、nginx、mysql、composer、node、wordpress:cli 六個 digest 全部相符），因內容定址，digest 相同即內容相同。`infra/versions.env` 以 `BASE_IMAGE_REGISTRY` 選擇來源，digest 不變。

## 框架設定鍵查核（2026-11-05，GAP-KEYRING-01）

| 設定鍵 | 查核結果 | 來源 |
|---|---|---|
| `APP_PREVIOUS_KEYS`（Laravel 13） | 環境變數為逗號分隔的舊加密金鑰清單，對應 `config/app.php` 的 `previous_keys`（`config('app.previous_keys')`）；加密只用目前 `APP_KEY`，解密先試目前 key 再依序試舊 key | 官方文件 `laravel.com/docs/13.x/encryption`「Gracefully Rotating Encryption Keys」；已安裝的 `laravel/framework` v13.40.0 原始碼 `Illuminate/Encryption/EncryptionServiceProvider.php`（`previousKeys(... $config['previous_keys'])`）與 `Illuminate/Routing/RoutingServiceProvider.php` 一致 |

本案以 `APP_PREVIOUS_KEYS_FILE` 讀檔後匯出為上述 `APP_PREVIOUS_KEYS`（`app/app/Support/Secrets/SecretFiles.php`），不改框架設定鍵名稱。
