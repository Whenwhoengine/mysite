## 映像 registry 備援（ADR-004）

Docker Hub 匿名拉取在本 VM 出現 `429 Too Many Requests`。同一批 Docker Official Images 也由 Docker 發布於 Amazon ECR Public（`public.ecr.aws/docker/library/*`）。本次以**相同 digest**從 ECR Public 實際拉取成功（php、nginx、mysql、composer、node、wordpress:cli 六個 digest 全部相符），因內容定址，digest 相同即內容相同。`infra/versions.env` 以 `BASE_IMAGE_REGISTRY` 選擇來源，digest 不變。
